# Sombra16 — prototipo v0.1

## Qué incluye
- Perfil de Sombra16 y pasado conocido.
- Diario con fecha, tipo de entrada, notas y fotografía.
- Historial de vacunas, desparasitación y otros registros de salud.
- Datos pendientes, microchip y notas de ADN.
- Exportación e importación de copia JSON.
- Almacenamiento local del navegador.

## Probar en Android
1. Copia `index.html` al móvil o abre el archivo desde un servidor local.
2. Para probar todas las funciones con mayor compatibilidad, abre la página desde un navegador Android moderno.
3. Los datos se guardan en el almacenamiento local del navegador de ese dispositivo. Exporta copias periódicas.

## Importante
Esta entrega es un prototipo web funcional, no un APK compilado. No envía notificaciones automáticas ni sincroniza datos en la nube. La siguiente fase es envolver la interfaz en un proyecto Android (por ejemplo, con Capacitor/Android Studio), probarlo en el dispositivo y generar una APK firmada. Antes de usarlo como registro único, realiza copias de seguridad.

## Privacidad
No incluyas datos personales innecesarios. Los datos de microchip y documentos deben mantenerse privados. La app no diagnostica enfermedades y no reemplaza al veterinario.
